# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.x | ✅ Active |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately by emailing the maintainer (see GitHub profile). Include:
- Clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if you have one)

Expect acknowledgment within **48 hours** and a fix within **7 days**.
